# Pontos-de-Brasilia


# 🏛️ Explore Brasília: Guia Turístico

Este é um projeto de site informativo sobre **Brasília**, a capital do Brasil, declarada Patrimônio Cultural da Humanidade. O site apresenta a arquitetura icônica de Oscar Niemeyer, o urbanismo de Lúcio Costa e os principais pontos de lazer da cidade.

## 🚀 Tecnologias Utilizadas

* **HTML5**: Estrutura semântica das páginas (index, eixo, história, etc.).
* **CSS3**: Estilização moderna com Flexbox e CSS Grid para responsividade.
* **Google Fonts**: Tipografia limpa e legível para conteúdo histórico.

## 📂 Estrutura do Projeto

O site está organizado nos seguintes arquivos para facilitar a navegação:

* `index.html`: Página inicial com as boas-vindas.
* `eixo.html`: Galeria de cartões com as principais atrações (Catedral, Planalto, Memorial JK).
* `historia.html`: Seção dedicada à construção da capital e aos Candangos.
* `pontao.html`, `parque.html`, `esplanada.html`: Páginas de detalhes sobre locais específicos de lazer e poder.
* `style.css`: Arquivo único de estilização para todo o projeto.

---

## 📸 Demonstração das Seções

### 1. Galeria de Atrações (Grid System)

A página **Eixo** utiliza um sistema de cartões que se ajustam a qualquer tamanho de tela.

* **Catedral Metropolitana**: Obra-prima com 16 colunas de concreto.
* **Palácio do Planalto**: Sede do Poder Executivo com colunas monumentais.
* **Memorial JK**: Homenagem ao fundador Juscelino Kubitschek.

### 2. Conteúdo Histórico

A página de **História** detalha o sonho de JK e a execução do Plano Piloto em apenas 41 meses.

> "Brasília foi construída para interiorizar o desenvolvimento do Brasil."

## 🎨 Design System

| **Fundo** | `#f4f7f6` (Cinza claro para leitura) |
| **Efeitos** | Hover com elevação em 3D nos cards |

## 🛠️ Como visualizar o projeto

1. Clone este repositório.
2. Certifique-se de que todos os arquivos `.html` e o `style.css` estão na mesma pasta.
3. Abra o arquivo `index.html` em um navegador moderno (Chrome, Edge ou Firefox) para garantir que as imagens carreguem corretamente.

## 🌟 Funcionalidades
* **Design Responsivo**: Layout que se adapta a computadores e celulares.
* **Menu Unificado**: Navegação fluida entre todas as seções (História, Atrações, Contato).
* **Arquitetura de Cards**: Exibição organizada dos pontos turísticos com efeitos visuais.
* **Conteúdo Educativo**: Seção dedicada à história da construção da cidade.

## 🛠️ Tecnologias
* **HTML5**: Estrutura semântica e acessível.
* **CSS3**: Estilização com Grid, Flexbox e variáveis de cores inspiradas na bandeira do DF.

## 📂 Organização das Páginas
- `index.html`: Boas-vindas e introdução.
- `eixo.html`: Os monumentos do Eixo Monumental.
